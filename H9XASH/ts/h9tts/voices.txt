// voices.txt -- the voice variants of H9's Kokoro text to speech.  ASCII only; // starts a comment.
//
// Read by the client library (reTS/cl_dll/h9_tts_catalogue.h) and by the helper process (tools/h9kokoro64), which must see the same file:
// the helper tells the client the checksum of the catalogue it loaded and the client refuses a helper whose checksum differs.
//
// One line per variant, in the order the players' numbers point into it.  NEVER reorder or delete a line of a shipped catalogue:
// cl_h9_tts_myvoice and the per-kind picks are numbers into these lists.  New variants are appended at the end of their kind.
//
//   default <kind> <index>
//   variant <kind> <index> <name> <lang> <blend> <speed> <depth> <chain> <mask> [note ...]
//
//   kind    man woman mech bot droid  (the speech kinds; bot and droid are two kinds, a droid is a bot voice with the droid byte in the tail of the H9Tts message)
//   index   1, 2, 3 ... without gaps inside a kind.  cl_h9_tts_myvoice N (1 .. 99) selects index ((N - 1) mod count of the kind);
//           N = 0 means the kind's default.  Every machine renders the same sound for the same N: the voice files, the speed, the depth
//           and the chains are all fixed here.
//   name    ASCII word, for console listings and the samples
//   lang    en-us or en-gb: the accent of the voices of the blend (a* American, b* British), for the listings; the helper speaks every variant from American phonemes.
//   blend   voice[:weight][+voice[:weight]...] -- Kokoro style files (voices/<name>.bin).  The weights of one blend are normalised to
//           sum 1 and the 510 x 256 style tables are averaged row by row (row r = sum_i w_i * row r of voice i); the row a line uses is
//           the number of its phoneme ids minus one.  A weight may be negative as long as the sum stays positive (not tried).
//   speed   Kokoro's own speed input (0.5 .. 2.0).  1.0 is the voice as trained.  Speeds above 1.15 cost intelligibility (word error
//           rate 0.09 -> 0.22 at 1.30 in the speed sweep), so the catalogue stays inside 0.95 .. 1.10.
//   depth   the variant's own depth steps; the speaker's cl_h9_tts_mydepth (-10 .. +10) and the slot step of cl_h9_tts_individual are
//           added, the sum is limited to -12 .. +12.  One step is a resample by 1.025 (pitch AND tempo move together, as today); the
//           kind's chain resample ratio and all steps are applied in ONE pass (chains.txt, step 3).
//   chain   machine kinds: the chain id of chains.txt (mech, bot, droid);   man and woman: -
//   mask    man and woman: the gas-mask chain id (mask_man, mask_woman), used when the speaker is on the mask list and
//           cl_h9_tts_muffle > 0;   machine kinds: -
//   note    free text.  "grade X" is the grade hexgrad gives the voice (VOICES.md), WEAK marks a voice graded D or worse.
//
// ORDER inside man and woman: best-graded and most intelligible first.  The kind's default is its first line.
//
// The lists were picked so that the variants of a kind sound as different as the voices allow: a farthest-point choice over every voice and blend
// at depths -5 to +5 (two variants of one kind count as different when their pitch differs by 2 semitones or their timbre by 3 dB).
