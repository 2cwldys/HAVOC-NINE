AmxxEasyHttp -- license of the AmxxEasyHttp files in this folder
==============================================================

AmxxEasyHttp is an HTTP client module for AMX Mod X by Igor Minin and the Next21 Team:
https://github.com/Next21Team/AmxxEasyHttp (MIT). ts_advertise, h9_presence, h9_community, h9_compete and
h9_rank need it (their #include <easy_http>).

In this folder
  easy_http.inc   AmxxEasyHttp's include file, which the plugins above compile against. It declares the same 47
                  natives, with the same signatures, as the easy_http.inc of the 1.4.0 release; it is not
                  byte-identical to that file (comments and layout differ).
