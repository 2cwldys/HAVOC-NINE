EXPORT-WEAPONS -- weapons made for H9 (The Specialists on H9XASH), one folder each
==================================================================================

Each folder holds a weapon's finished files laid out as they go in the game (ts\models\h9, ts\sound\h9\<weapon>,
ts\sprites), the scripts that make them (build\), its credits, and a README that says what the game needs besides
the files: the weapon's row in reTS's weapon table, the client's tables and effects, TSX's tables and the match
mode's class lines.

  laserrifle\   weapon 40, the laser rifle: an energy weapon (green plasma bolts) on the M4A1's own models
