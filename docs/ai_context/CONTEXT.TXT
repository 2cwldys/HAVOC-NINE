### Class Limits (tsm_class_limits)
"0,4,2,2,4,2,1" - Assault unlimited, Engineer 4, Marksman 2, Heavy 2, Breacher 4, Medic 2, Officer 1

### Perks (TSM_PERK_*)
- TSM_PERK_NONE = 0
- TSM_PERK_ENGINEER = 1
- TSM_PERK_BREACHER = 2
- TSM_PERK_MEDIC = 3
- TSM_PERK_OFFICER = 4
- TSM_PERK_REGEN = 5 (Heavy has this)

### Class Menu System
- Classes chosen via menu at round start
- g_player_class[MAXPL] stores chosen class (0 = not picked)
- Class locked for whole match
- apply_class() applies loadout, model, health, etc.
- g_class_menu_at tracks menu cooldown

### Sprites
- tsm_class.spr - class selection icons
- tsm_panel.spr - panel background
- tsm_banner.spr - banner display
- tsm_typing.spr - typing indicator
- Location: TSM/export/ts/sprites/

### Model System
- Models defined per class per team (team1|team2 format)
- mp_teammodels in ts/game.cfg must include all models
- Model verification at map load
- tsm_model_mode "force" enforces class models
