==========================================

     BUILDING FROM THIS REPOSITORY

==========================================

FIRST INSTALL GIT LFS (https://git-lfs.com), THEN IN THE CLONE: git lfs install, THEN git lfs pull.
THE MAPS AND MODELS LIVE IN GIT LFS. WITHOUT IT THE BUILD SCRIPTS STOP AND NAME THE FILES THAT ARE ONLY POINTERS.

EVERY BUILD IN THIS REPOSITORY AND WHERE IT STARTS: docs/BUILDING.txt

THE WEB CLIENT BUILDS FROM A FRESH CLONE ON WINDOWS WITH ONE COMMAND: build-webclient.cmd
IT FETCHES EMSCRIPTEN 6.0.12 (WITH ITS OWN PYTHON, NODE AND NINJA) AND CMAKE 4.3.0, ABOUT 820 MB, EACH FILE
CHECKED AGAINST A PINNED SHA-256, THEN BUILDS THE ENGINE AND THE reTS CLIENT FOR WEBASSEMBLY AND LAYS OUT THE
GAME FILES IN webclient-build\. THE FIRST RUN TAKES ABOUT 10 MINUTES.
VERSIONS, CHECKSUMS AND STEPS: docs/BUILDING.txt SECTION 9.
