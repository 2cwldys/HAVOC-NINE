//  EntMod admin list  --  copy this to:  addons/EntMod/DF_admins.txt
//
//  Each line grants one person EntMod admin. Three fields, separated by ";" :
//
//        id ; password ; flags
//        --   --------   -----
//         |       |        '-- the powers to grant (a number; 65535 = everything)
//         |       '----------- a password YOU invent for that person (see below)
//         '------------------- WHO they are (their id)
//
//  --- field 1, the id --- use ONE of these to identify a person:
//        STEAM_0:1:12345678                    a SteamID (on a Steam server)
//        a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6      an H9XASH id (h9_clientid), 32 hex
//        ID_0123456789abcdef0123456789abcdef   the engine's ID_ form
//      On H9XASH prefer the h9_clientid: it follows the person's havoc9.org
//      account and survives an IP change. Type `status` in the server console
//      to see the ids of who is connected.
//
//  --- field 2, the password --- IMPORTANT: this is NOT a fixed keyword. It is a
//      secret string YOU choose for that admin (anything you like). The admin
//      then types it once in their own game console:
//            setinfo _entpass THE-SAME-PASSWORD
//      The id only selects the line; this password is the actual key, so pick a
//      real one and keep it private. It is compared case-insensitively.
//
//  --- field 3, the flags --- 65535 grants every EntMod power.
//
//  Lines starting with # or // are ignored. EntMod re-reads this file every 10
//  seconds -- no server restart needed after you edit it.
// ============================================================================
