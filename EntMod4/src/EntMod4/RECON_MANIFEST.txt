--------------------------------------------------------------------------------
SCOPE DECISION -- what is reconstructed vs. what is NOT
--------------------------------------------------------------------------------
The existing tree builds EntMod as a PURE METAMOD plugin (modmain/h_export/dllapi/
engine_api, NULL hook tables). Two large blocks of the original binary belong to its
OTHER personality -- a standalone game-DLL shim -- and are OUT OF SCOPE here:

  OUT-1  ~612 entity-classname trampolines  aiscripted_sequence..adminmod_timer
         decompile lines ~5000-22025  (addr 0x38190-0x466b0)
         Each is identical: dlsym(h_Library,"<name>") cached in a function-local
         static, then tail-call. They are EntMod's exported entity factories for
         when it loads AS the game DLL. The metamod build never exports entities
         (the real game DLL does), and AddGameEntity/Create use the engine's
         CREATE_NAMED_ENTITY, not dlsym. If ever needed: one generated file
         gameents.cpp via a LINK(name) macro + h_Library. NOT written now.

  OUT-2  ~380 engine/gamedll pass-through wrappers + Post hooks + the pfnXxx engine
         interceptors + GiveFnptrsToDll(as gamedll) + GetEntityAPI(v1)
         decompile lines ~1-5000 and the *_Post block (addr 0x32550-0x37a50)
         These are the shim's plumbing. In the metamod build they are the NULL
         table entries already present in dllapi.cpp / engine_api.cpp. NOT written.

IN SCOPE = the custom EntMod logic, decompile lines 22173-33103 (addr 0x46a70-
0x58a10), plus the dispatch bridges at lines 1434-1680 (addr 0x337f0-0x33c80).
~150 functions, partitioned below.

link-completeness and who-blocks-whom, not per-file compilation.

                                      DELETE stubs.cpp (defines DFEntMover + DFEntAdmin).
  6. dll.cpp                       -- EXPAND the six handlers to their full bodies.
  7. mapcycle.cpp                  -- last; drop if proven unreachable.
  Verify after each with scripts\debug-compile.ps1 (-ReportOnly) per project rule.
