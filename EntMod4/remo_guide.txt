//How to Change weapon models:
 
e_add weapon_9mmhandgun:origin:%HERE%:iuser1:models/p_shotgun.mdl:iuser2:models/p_shotgun.mdl:iuser3:models/ball.mdl:
 
Instructions:
1. Go to weapons room. Look at every weapon.
2. Type "entities" in the console (without the quotes), and go to the part with a bunch of models with w_ infront of them. these are all valid models for weapons. You can replace "w_" with "p_" or "v_".
Examples: w_9mmhandgun, w_shotgun, w_9mmar.
 
 
 
W_ models are WORLD models.
V_ models are FIRSTPERSON models.
P_ models are PLAYER models(the model when player is holding the weapon)
 
                      Model keys:
 
iuser1 - user thirdperson model (model while player is holding the weapon)
iuser2 - world
iuser3 - first person model
 
Example:
e_add weapon_shotgun:origin:%HERE%:iuser1:models/p_9mmhandgun.mdl:iuser2:models/w_9mmhandgun.mdl:iuser3:models/v_9mmhandgun.mdl:
 
The above would make a shotgun that has all Hand Gun models.

//TriggerCondition
TriggerCondition:<number> add this in an add line now u can give a monster a target for a new command
ex: if u attack a monster the monster is starting a monstermaker
 
numbers:
0 - No Trigger (default)
1 - See Player, Mad at Player
2 - Take Damage
3 - 50% Health Remaining
4 - Death
7 - Hear World
8 - Hear Player
9 - Hear Combat
10 - See Player Unconditional
11 - See Player, Not In Combat
 
ex:
e_add monster_zombie:origin:%HERE%:health:500:displayname:i am da evil zombie:TriggerCondition:4:TriggerTarget:test:
than do a monstermaker with targetname test and if the monster dies the monstermaker will spawn new 1

//all explained^^ i copied the list below from a nother site i got from google:
 - Pulls out your entity mover. "Shoot" it at an entity to move it.
e_telestart <name>
 - Creates a teleport opening. The portal will lead to an exit made with e_teleend of the same name.
e_teleend <name>
 - Creates a teleport exit. The portal will begin at an entrace made with e_telestart of the same name.
e_teledelete <name>
 - Deletes a portal with the name specified.
t_select <name>
 - Selects an entity to be made into a train with the name specified. Name must be unique.
t_start
 - Begins setting the path for the train selected.
t_end <speed>
 - Ends the path for the train selected. An average speed is about 250, a slow speed is 100. Any number can be entered for the speed.
t_go
 - After setting the path, this will start the train.
e_use
 - "Uses" the entity. Different entities do different things. For example, using this on a breakable window will cause the window to break.
e_god
 - Gives the entity god mode (can't take damage).
e_render <mode> <amt> <fx> <render color r> <render color g> <render color b>
 - All parameters are optional. Enter a -1 for no change on any of the parameters. It's hard to explain this command in a few lines, but if you're a Half-Life mapper or coder, chances are that you'll understand this. More info on this command to come later.
e_drop
 - If the entity is close enough to the ground, it will cause the entity to drop to the ground. Doesn't always work with rotated entities.
e_rotate <x> <y> <z>
 - Rotates an entity.
e_rotate_x
 - A quick command to rotate an entity 15 degrees on the x axis.
e_rotate_y
 - A quick command to rotate an entity 15 degrees on the y axis.
e_rotate_z
 - A quick command to rotate an entity 15 degrees on the z axis.
e_add <classname>:<key 1>:<value 1>:<key 2>:<value 2>....
 - Adds any entity with any keys and values you want. %HERE% can be used in the command to stand for your current origin. For example, to add a turret in TFC that shoots team 2 (Red) at your location type in the console: e_add
monster_zombie:origin:%HERE%:is_player_ally:1:displayname:killarag:health:1000 team:team_no:2  Make sure you DON'T INCLUDE quotes. Also, make sure the entity that you're trying to create is precached (a good way to check is to see if one is already in the map). This example could be used on well with no problems, but isn't limited to well.
 
e_kill
 - Kills the entity that you're looking at. If you're looking at a player it will kill him or her. However, it won't kill players in some mods. 
e_classname <classname>
 - Sets the classname of an entity.
grabtype <classname> <search range>
 - Searches for an entity of a certain type within a certain range to grab.
stopgrab
 - Drops an entity grabbed with grabtype.
+grabent
 - When bound to a key, it can be used to move entities. Just look at an entity and hold down the key. When you let go, the entity will be dropped.
+copyent
 - Works the same way as +grabent except it copies the entity and not just move it.
e_undo
 - Undos an entity move or deletion.
showx
 - Draws a line pointing in the positive x direction.
showy
 - Draws a line pointing in the positive y direction.
showz
 - Draws a line pointing in the positive z direction.
e_stack <count> <x offset> <y offset> <z offset>
 - Stacks the entity you're looking at a certain amount of times a certain offset of units away from the previous each time.
mm_grab
 - Selects an entity to be moved. You can select up to 128 to be moved at one time.
mm_start
 - Starts moving the selected entities.
mm_end
 - Drops the selected entities. This is also used to drop entities that follow you when loaded.
e_show <classname>
 - Shows all entities of a specific type.
es_start <name>
 - Starts an entsave. Name it whatever you want. If it already exists it will be overwritten.
es_grab
 - Selects the entity you're looking at to be saved.
es_graball <classname> (targetname)
 - Grabs all entities of a certain type. You can optionally specify a target name to grab a certain group of ents.
es_ungrab
 - Removes the last grabbed entity from the selected entities.
es_save <1/0>
 - Saves the entities. If the parameter is 1, it will follow you on load. It will be the same distance away as the distance between you and where it is now.
es_list
 - Doesn't work in Linux. Shows all entities saved on the current map.
es_listall
 - Doesn't work in Linux. Shows all creations.
es_load <name>
 - Loads a creation. If it follows you on load, use mm_end to drop it.
entmod_addpack <team> <regen wait>
 - TFC only. Adds an ammo pack.
entmod_lookingat
 - Shows info about the entity you're looking at.
entmod_worldcopy <x> <y> <z> <angles x> <angles y> <angles z> <spin x> <spin y> <spin z>
 - Creates a copy of the map at a certain offset, rotated a certain amount of degrees on each axis, and spinning a certain speed. Use the following command to kill all copys: e_kill "DF_worldcopy" 9999
entmod_create <classname> <1/0>
 - Creates a respawning entity ahead of you. Use 1 for the second parameter to bypass any precache warnings, but be aware that doing so could cause a crash.
entmod_quickmake <classname> <1/0>
 - Creates an entity at your location. Use 1 for the second parameter to bypass any precache warnings, but be aware that doing so could cause a crash.
entmod_spawn <classname> <offset x> <offset y> <offset z> <1/0>
 - Creates an entity a certain offset from your location. Use 1 for the second parameter to bypass any precache warnings, but be aware that doing so could cause a crash.
entmod_spawn
 - Creates an entity at a certain location. Use 1 for the second parameter to bypass any precache warnings, but be aware that doing so could cause a crash.
e_search
 - Lists entities in your area.
entmod_keyvalue <key> <value>
 - Sets a key and value on the entity you're looking at
entmod_noclip 1 or 0
entmod_noclip on or off
