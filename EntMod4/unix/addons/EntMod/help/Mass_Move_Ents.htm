This section will explain how to mass move ents in Ent Mod:

 

Command Use:

mm_grab

Usage:
mm_grab

Description:
Selects an entity to be mass moved

mm_start

Usage:
mm_start

Description:
Starts the mass move process once all entities have been grabbed.

mm_end

Usage:
mm_end

Description:
Drops all entites being mass moved. Also used for entities that are green and follow you when loaded.

 

First, you will need to enter the mm_grab command while looking at one of the entities you want to grab:

 

 

As you can see in the picture above the command mm_grab was entered. Remember that this command is entered while looking at the entity you want to grab. Keep entering this command untill all of the ents you want to move at once are selected.

 

Next, we can see the effect of this command after enter was pressed:

 

 

As you can see in the picture above the entity turns green to let you know that it has been selected.

 

Next, we will enter the mm_grab command untill all ents we want are grabbed. Once we have done that we enter mm_start into the console to start the moving process.

 

After you have entered the mm_start command, the entities will follow you when you move.

 

 

As you can see in the picture above all entities we wanted were selected and moved to the new location we want to place them in.

 

Next, you will need to enter the mm_end command:

 

 

As you can see in the picture above the mm_end command was entered. When this command is entered all ents you are currently holding with the mm_grab command will be let go.

 

Next, we can see the effect of this command after enter was pressed:

 

 

As you can see in the picture above the ents were let go and turned back to their normal state.

 

This example was done with the Team Fortress Classic mod but this example holds true for all Half-Life mods.
