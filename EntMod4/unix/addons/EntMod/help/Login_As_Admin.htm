This section will explain how to log in as an admin to Ent Mod:

 

First, see the Add Admins section of this help file to make sure you are an admin.

Next, while in the Ent Mod server, bring down the console and type this in:

 

    • setinfo _entpass "passwordhere"

 

Be sure to replace "passwordhere" with your actully password in the DF_admins.txt file.

 

Once you have done this, you can type "weapon_entmover" in the console or any admin command to see if it works. If it does, you know that Ent Mod sees you as an admin.
