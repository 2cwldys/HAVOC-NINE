This section will explain to you how to use the e_classname command in Ent Mod:

 

Command Use:

e_classname

Usage:
e_classname <classname>

Description:
Sets the classname of the entity being looked at. Useful to turn doors into walls so that they won't move.

Example:
e_classname func_wall

 

In this example we will turn a door into a wall.

First find and copy a door on the map. Now run the command e_classname func_wall in the console. Then make a copy of the door you ran the command on and this copy will be a wall that doesn't move and not a door.
