This section will explain to you how to load saved entities in Ent Mod:

 

Command Use:

es_list

Usage:
es_list

Description:
Lists all entity saves for the current map.
Not available on Linux versions of Ent Mod.

es_listall

Usage:
es_listall

Description:
Lists all entity saves on the server.
Not available on Linux versions of Ent Mod.

es_load

Usage:
es_load <name>

Description:
Loads the specified entity save. Saves can only be loaded on the map they were saved on.

 

In this example, we will be loading a bridge saved on the map 2fort for TFC. To do that, we enter es_load bridge in the console.

After that has been done, the bridge appears in it's saved location.

 

Another example would be loading a saved cage on the same map. By entering es_load cage it loads green and follows us. It's following you because it was saved with the follow option.

To stop it from following you, run the mm_end command in the console.

 

If you wish to see a list of all entity saves on the current map you would type the es_list command into the console. A window will appear on your screen with the enities you can load. If none are found for the current map, it will say "No entities to load."

If you want to see all entity saves on the server, type the es_listall command into the console. A window appears on your screen with the map and name of the save for each entity creation saved on the server. If no entity saves are found at all, it will say "No entities to load."

 

Note: The es_list and es_listall commands are not available on the Linux version of Ent Mod.
