Ent Mod is a server-side based multi-mod Entity Mover. Ent Mod adds endless hours of fun to any Half-Life Mod!

 

Ent Mod v3 is:

  • Compatible with Steam
  • Compatible with Normal Half-Life
  • The most feature fulled Ent Mod yet!

 

 

(Please note that Ent Mod is a Metamod plugin but can also run without Metamod.)
