This section will explain how to get Ent Mod working:

 

To begin the you need to download the Ent Mod's install file here.

 

Next, you will need to unzip the files to one of the following locations:
NOTE:
To unzip the files you will need an unzip program such as WinZip or WinRar.

 

Normally:

    • C:\SIERRA\Half-Life\<mod> (for normal Half-Life)
    • C:\Program Files\Steam\SteamApps\<username>\half-life\<mod> (for Steam Half-Life)
    • C:\Program Files\Steam\SteamApps\<username>\dedicated server\<mod> (for dedicated Steam server)
    • C:\HLServer\<mod> (for the dedicated server)

 

Next, you will need to decide if you will be using Metamod or not.
It is best to use Metamod as you can easily add other mods later.
To add other mods later (such as the RadioMod) all you need to do is add the dll to the plugins.ini Metamod file.


Use Metamod for best support and compatibility with Ent Mod.

 

If you will be using Metamod see this installation help -> With Metamod

If you will not be using Metamod see this installation help -> Without Metamod
