This section will explain to you how to move entities in Ent Mod:

 

Command Use:

+grabent

Usage:
+grabent

Description:
Starts moving an entity. The entity follows you while you have a key bound to this held down.
It is best if this command is bound to a key.

-grabent

Usage:
-grabent

Description:
Lets go of the entity being grabbed. If you bind +grabent to a key, this is automatically ran when you let go of the key.

 

This is best done when using a key bound to +grabent. So first bind any key you want to it (See How to Bind Keys ).

Now, look at an entity you want to move and then press and hold the key that you bound +grabent to. It will then begin to follow you. When you let go of the key, it stops following you and stays where you dropped it.
