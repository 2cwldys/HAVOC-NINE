This section will explain how to bind keys while in-game to use for Ent Mod:

 

Most of Ent Mod's features are activated by special commands. If you want to use a key for the special commands, instead of having to type it in the console each time, you'll need to bind it to a key. Binding is simple. To bind "+grabent" to the key "X", just type this in your console:

 

    • bind x "+grabent"

 

Now everytime you hit the "X" key, the +grabent feature will be activated. This will work for all other commands as well, for example:


Bind "Y" to "weapon_entmover"

    • bind y "weapon_entmover"

 

Bind "Q" to "+copyent"

    • bind q "+copyent"
