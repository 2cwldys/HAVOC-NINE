This section will explain to you how to use the e_show command in Ent Mod:

 

Command Use:

e_show

Usage:
e_show <classname>

Description:
Puts a green plus sign and visible bounding boxes at the location of every entity of the specified type.

 

In this example, we will e_show to show us where all the func_nobuilds are on the map.

First, run the e_show func_nobuild command. Now you will see a grey bouding box and a green plus sign where all func_nobuilds are.

 

Note: Only so many of the grey bounding box dots can be displayed at once. Also, if there are a large quantity of the entity you are showing, some of the green plus signs may not be shown.
