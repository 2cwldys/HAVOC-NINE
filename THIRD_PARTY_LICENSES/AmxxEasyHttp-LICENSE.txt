AmxxEasyHttp -- license of the AmxxEasyHttp files in this folder
==============================================================

AmxxEasyHttp is an HTTP client module for AMX Mod X by Igor Minin and the Next21 Team:
https://github.com/Next21Team/AmxxEasyHttp (MIT). ts_advertise, h9_presence, h9_community, h9_compete and
h9_rank need it (their #include <easy_http>).

In this folder
  amxx_easy_http_cacert.pem   the CA bundle the module reads to check the servers it talks to over HTTPS: Mozilla's
                              root certificates as curl extracts them (the data of 12 Dec 2023, the same date as the
                              bundle AmxxEasyHttp 1.4.0 ships). It is data, not AmxxEasyHttp code; the module's license
                              is below because it is the module's own file.
