THIRD_PARTY_LICENSES -- the license texts of other people's work in this repository, gathered in one place
===============================================================================================

These are copies. Each original stays beside the code it belongs to (a third-party file ships with its license in every
folder that holds a copy of it), and a folder's own license file wins for that folder. LICENSING.md lists what each file is
and which license it is, and says how these sit beside the project's own GPLv3 plugin code and Half-Life SDK mod code.
