Very important if you want servers to show on the list:
=======================================================

The master server address is set on the servers page, in servers/index.html, on the #serverBoard element:
<div id="serverBoard" class="server-board" data-master="/api/servers" data-refresh="30">

data-master is /api/servers: h9web lists the servers in its servers.json there, live (h9web/README.txt, section 6).
It is the same list the web client relay and the game server browser in the browser use, so a server added to
servers.json shows on the page, in the browser game and on the account page at once.

To show the bot list instead, set data-master to the bot JSON list (served over https, as the site is), for example:
data-master="https://YOUR.HOST.HERE/v1/servers/ts.json"
