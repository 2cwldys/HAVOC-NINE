WHAT THE SERVERS SEE

Your player id stays with this account for good. When you play in the browser, the game sends it to each H9 server mixed with that server's own address, as h9_clientid: every server sees its own value for you, the same one on every visit, and no two servers can match you up by it. Below is what each H9 server sees; a server admin can use it to tell you apart from everyone else.

YOUR PLAYER ID

Optional. The downloaded H9XASH client makes up a random id of its own, and that keeps working. To have the servers see the downloaded client and the web client as the same player, put this account's id into H9XASH: run enter_userid.cmd in the H9XASH folder and paste it, or write it into H9XASH\user_id.ini as id= under [client]. WHAT WE KEEP, AND WHY

An account here holds:

  • your username;
  • your password, only as a salted scrypt hash: nobody can read it back, us included;
  • when the account was made, when you last signed in, and when the password last changed;
  • your role (player, moderator or admin), and a suspension with its reason if there ever is one;
  • a random number made for the account, from which your player id is worked out with a key only the server knows;
  • your signed-in sessions: a hashed token and when it was made and last used, until you sign out or it runs out (30 days at most);
  • your profile picture, if you add one, with the details a picture file carries (such as the camera and the place it was taken) removed;
  • a username change you ask for, and your earlier name, kept reserved for you for 30 days after a change;
  • if you sync your Discord: its user number and display name, and when it was linked. The registered role in H9's Discord follows the link; only an admin can free it.
  • when you play on an H9 server as this account, or in the web client: which server and since when, the name you used in game, your playtime per server, and when you were first and last seen. Finished sessions are kept for 90 days. For the id check, a hash of each device that proved your player id, and a keyed hash of the first part of your network address for 30 days; only admins see those, as "known" or "new". The switches under WHAT OTHERS SEE decide what everyone else sees.

When a moderator or an admin acts on your account or on what you wrote (a suspension, a removed post, a name change), an audit log records who did what and when, kept for up to 90 days.

No email address, no real name, no tracking or advertising cookies. The one cookie is the session cookie that keeps you signed in.

Why: to sign you in, to keep the web client for members, and so that H9 servers know a returning player. What a server keeps against its h9_clientid, such as stats or a ban, is up to that server.

The server's logs note sign-ins, failed sign-ins and web client connections by username, and the web server's access logs note IP addresses. Both are kept for up to 30 days, to run the site and stop abuse. When you play in the browser, game servers see the relay's address, not yours.

To delete your account and everything above, ask an admin on Discord.
