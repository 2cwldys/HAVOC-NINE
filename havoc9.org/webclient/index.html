WEB CLIENT

IN PREPARATION

HAVOC 9 in your browser is being prepared. The H9XASH engine and the game's own client still have to be built for WebAssembly; this page starts the game as soon as they are published here.

Until then, play with the native H9XASH client.

GET THE CLIENT VIEW SERVERS

WHAT YOU WILL NEED

  1. A HAVOC 9 account: a name and a password, nothing else. Create one in a minute.
  2. A desktop browser with WebGL 2: a current Chrome, Edge or Firefox, with hardware acceleration turned on.
  3. A keyboard and a mouse. Click the game to give it the mouse; Esc gives it back.
  4. Time on the first start: the game's files are fetched as the game needs them, and the browser keeps them for the next visit.
  5. Your settings and key bindings are kept in this browser only.
