SMAK — STUDIO MODEL AGENT KIT

SMAK is an AI-driven toolkit for GoldSrc models and maps. An agent can retexture weapons, replace shapes, edit animations, modify viewmodels, import .fbx/.glb, handle RCBot waypoints, generate maps, and render previews — all without Blender, Hammer, BSPview, or studiomdl.

It lives in the SMAK/ folder of the repo. Point your agent at SMAK/AGENTS.md and start with a small texture change to prove the pipeline.
