AMBuild's license
=================

linux/h9build-setup.sh --with-ambuild installs AMBuild, the build system of AMX Mod X, from
https://github.com/alliedmodders/ambuild (version 2.0, commit 5b0aa725beef33c9cf6a1b00659a010c3d9120d3,
2026-11-08, the one this was checked against) into the Linux build environment, and
linux/build-linux.sh runs it to build AMX Mod X and its modules. AMBuild is not part of this repository
or of any package H9 distributes: it is downloaded on the machine that builds. Its license, the BSD
3-Clause license, is kept here beside the scripts that use it, as that license asks of any copy of the
tool, and wherever this folder goes in the repository. It is compatible with the MIT and the GNU GPL
version 3 licenses the rest of the project is under.
